# El Legado de Mandji

Proyecto independiente de Iniciativas Elebi para una aventura historica digital interactiva sobre patrimonio, memoria y restitucion cultural.

## Prototipo publicado

https://el-legado-de-mandji.eleela289502.chatgpt.site

## Estructura

- `site/`: prototipo web interactivo.
- `docs/`: Biblia y documentacion del proyecto.

## Estado

- Landing page dedicada.
- Sala de reuniones interactiva.
- Flujo de hotspots progresivos.
- Dossier MND-01 con documentos iniciales.
- Fotografia explorable con efecto 2.5D.
- Animacion de aproximacion al Golfo de Guinea.
- Contador de pistas por escena.
- Perfiles de lideres de mision: Andre Esono Bibang, Lucia Nve Garcia y Christian Dougan Makosso.
